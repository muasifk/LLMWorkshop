# Challenge 2: Use an LLM to write and send an email automatically

## Objective
Design a flow where an LLM (via Agent Mode or MCP) completes a full email task:
- The user initiates the task (e.g., “Send a follow-up email to a client”)
- The LLM drafts the message
- The LLM sends the email or saves it to drafts autonomously, without further user action


## Requirements
- Provide a realistic scenario and explain the prompt structure or logic
- Show that the message is actually sent or saved to the user’s email client
