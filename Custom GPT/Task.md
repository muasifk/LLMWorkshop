
# Challenge 1: Build a task-organizing custom GPT

## Objective
Create a Custom GPT that helps users structure their daily tasks by:

- Time requirement (short / medium / long)
- Cognitive complexity (low / medium / high)
- AI involvement – identify where ChatGPT could assist and provide starter prompts


## Requirements
- Ensure clear role instructions, prompt examples, and logic for how tasks are labeled


## Deliverables
- Share the Custom GPT link (or equivalent setup)
- Provide the system message or configuration used to define the GPT’s behavior
